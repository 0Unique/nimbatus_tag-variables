# nimbatus_tag-variables
 
allows you to put variables into tags which can be changed and access mid game

variables are put within {}
to change a value you put an = after what you want to change, like this
{varA = 1+1}
you can also use the var in the assignment, like this
{varA = varA + 1}

can do basic math: addition (+), subtraction (-), multiplication (\*), division (\\)
